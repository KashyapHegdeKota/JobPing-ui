# Jobs page UI revamp

Status: in progress.

Scope is limited to the jobs route presentation: `src/app/page.tsx`, the jobs
feed, cards, filters, combobox, and the page-scoped stylesheet. Data fetching,
filter semantics, URL synchronization, analytics events, and browser navigation
contracts remain unchanged.

Figma source was unavailable because the Starter tool quota was exhausted. The
implementation follows the approved browser-reference direction: pale gray
canvas, dark navy typography, white bordered cards, mint and emerald accents,
and compact rounded controls.
